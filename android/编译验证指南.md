## 路径 B · 本地 Android Studio

1. 装 **JDK 17**（Temurin / Microsoft Build of OpenJDK 均可）和 **Android Studio**（Hedgehog 或更新）。
2. SDK Manager 里勾 **Android SDK Platform 34** + **SDK Build-Tools 34.0.0**（`compileSdk = 34`）。
3. Android Studio → Open → 选 **`android/` 目录**（不要选仓库根目录，根不是 Gradle 工程）。
4. 等 Gradle Sync 完成；首次会下载 Gradle 8.9 和依赖，需要能访问 mavenCentral / google()。
5. Build → Make Project，或终端里：

   ```
   cd android
   ./gradlew assembleDebug
   ```

6. 产物：`android/app/build/outputs/apk/debug/app-debug.apk`。

## 路径 C · 只有命令行、没有 Android Studio

装 JDK 17 + Android command line tools，设置 `ANDROID_HOME` / `ANDROID_SDK_ROOT`，然后：

```
sdkmanager "platforms;android-34" "build-tools;34.0.0" "platform-tools"
cd android && ./gradlew assembleDebug
```

## 常见失败排查

| 现象 | 原因 / 处理 |
| --- | --- |
| `Could not determine java version from '17.x'` 或 Gradle 起不来 | Gradle wrapper 版本与 JDK 不匹配，确认用 JDK 17（`java -version`），不要 JDK 21 |
| `SDK location not found` | 缺 `ANDROID_HOME`，或在 `android/local.properties` 里写 `sdk.dir=<你的SDK路径>`（该文件不要提交） |
| `Failed to find Platform SDK with path: ...android-34` | SDK Manager 装 Platform 34 |
| `Unresolved reference: PetManifest / PetState` | 工程文件没同步完整，确认 `android/app/src/main/java/com/lulu/pet/model/PetManifest.kt` 和 `PetState.kt` 都在 |
| `Duplicate class` / `package ... does not match` | 源码目录与 package 声明不一致；跑 `python .research/verify_project.py` 定位 |
| 依赖下载超时 | 检查网络能否访问 `maven.google.com` / `repo1.maven.org`；国内可配镜像 |
| `INSTALL_FAILED` / 装不上 APK | 签名或 minSdk 问题；本项目 `minSdk 26`（Android 8.0+） |
| 编译过了但桌宠是空白 | **不是编译问题**：36 张帧没进 assets，跑一次 `python assets/lulu/sync_assets.py` |

| 工作流 | 触发条件 | 产物 |
| --- | --- | --- |
| `Android build` | 推送改动到 `android/**`、`shared/**`、`assets/lulu/**`；或 Actions 里手动 Run workflow | `lulu-pet-debug`（内含 `app-debug.apk`） |

下载产物：Actions → 点对应工作流 → 最新一次运行 → 页面底部 **Artifacts**。下载**必须登录 GitHub**（匿名调 API 返回 401），产物默认保留 90 天。

已实测：2026-11-14 首次推送，`iOS Build` 全 13 步通过（1.2 分钟），产物 7.36 MB。

**已知怪癖**：首次推送空仓库时，`Android build` 没有自动触发 —— 它同时声明了 `branches: [main]` 和 `paths:`，而 `iOS Build` 只声明了 `paths:`（没跑）。后续只要推送落在过滤路径内都会正常触发；要立刻跑就在 Actions 页面点 `Run workflow`。
