# iOS 打包与安装指南（iPhone 17 / iOS 26.6.1）

## 先说结论：这个包我在这里做不出来

`.ipa` 的产出必须有 **macOS + Xcode**，这不是配置问题，是工具链物理不存在于 Windows 上。同时装进你的 iPhone 还需要**你自己的 Apple ID 签名**——我没有你的账号，也不该有。

所以「拿到一个能装的包」只有三条路，任选一条：

| 路线 | 成本 | 说明 |
| --- | --- | --- |
| **A. GitHub Actions**（推荐） | 免费，需要 GitHub 账号 | 云端 macOS 机器出未签名 ipa，你在 Windows 上用 Sideloadly 重签。本指南按这条写 |
| B. 借一台 Mac | 免费，需要 Mac | `cd ios && xcodegen generate`，Xcode 里真机 Run，一步到位 |
| C. 租云 Mac | 按小时付费 | MacinCloud / MacStadium 之类，本质等同 B |

工程代码、配置、CI 工作流、签名方案都已经铺好了，**卡点只在你按一下按钮**。

---

## 第一步：把工程推到 GitHub（只需一次）

仓库已在本地初始化并提交好（`main` 分支），你只需要建个空仓库再推：

1. 打开 <https://github.com/new>，仓库名随意（比如 `lulu-pet`），**不要**勾 README / .gitignore / license
2. 然后在本地执行：

```bash
cd F:/手机桌宠
git remote add origin https://github.com/<你的用户名>/lulu-pet.git
git push -u origin main
```

> 私有仓库完全可以，Actions 在私有仓库同样有免费额度。macOS runner 消耗 10 倍分钟数，这个工程单次约 5–8 分钟，折算约 50–80 分钟额度。
> 首次 push 会弹浏览器登录 GitHub，正常走一次授权即可。

## 第二步：跑 iOS Build

GitHub 页面 → **Actions** → 左侧 **iOS Build** → 右侧 **Run workflow** → **Run workflow**。

**默认不勾任何选项**就是最好的选择：出「纯主 App」包。

为什么默认不出小组件，理由很硬：

- 免费 Apple ID 只能给**主 App** 建 provisioning profile，包里内嵌的 `PetWidget.appex` 用的是另一个 bundle id，Sideloadly 重签时很可能报 `Application is missing the application-identifier entitlement`，**直接装不上**
- 免费账号也拿不到 **App Groups**，小组件本来就读不到主 App 的养成数值，装了也是空壳

所以默认给的是「能装、能跑、主 App 功能完整」的版本。等你有 99 美元/年的开发者账号，再勾 `include_widget` + `include_app_group` 出全量包。

跑完后：

- 页面底部 **Artifacts** → 下载 `LuluPet-unsigned-ipa`
- 解压得到 `LuluPet-unsigned.ipa`（约 20–30 MB，含 36 张立绘）
- 如果编译失败，下载同一个 artifact 里的 `build.log`，最后 200 行会直接打印在 Actions 日志里

workflow 做的事实上是：装 XcodeGen → 从 `shared/` 同步素材 → 生成只含主 App 的 spec → `xcodegen generate` → `xcodebuild -scheme PetApp -configuration Release CODE_SIGNING_ALLOWED=NO` → 把 `PetApp.app` 塞进 `Payload/` 打 zip。

## 第三步：Windows 上签名安装

两个一次性工具：

1. **Apple Devices**（微软商店搜 "Apple Devices"，微软官方那个）—— iPhone 驱动与设备通信
2. **Sideloadly**（<https://sideloadly.io>）—— 用你的 Apple ID 重签

操作：

1. iPhone 用数据线连电脑，手机上点「信任此电脑」
2. 打开 Sideloadly，把 `LuluPet-unsigned.ipa` 拖进 `iPA` 框，`Apple ID` 填你的 Apple ID
3. 点 **Start**，输入密码（开了双重认证会在弹窗里要一次验证码）
4. 装完在手机上：**设置 → 通用 → VPN 与设备管理 → 开发者 App → 信任**
5. 首次运行若提示开发者模式：**设置 → 隐私与安全性 → 开发者模式 → 打开 → 重启手机**

打开后应该看到：水豚噜噜站在屏幕中间呼吸起伏，点它会换姿势并冒出台词，下面三条数值（饱食度 / 心情 / 亲密度）会实时变；右上角齿轮进设置页。

### 免费 Apple ID 的三个硬限制

| 限制 | 说明 |
| --- | --- |
| **7 天过期** | 每 7 天用 Sideloadly 重签一次，否则点开闪退 |
| **最多 3 个自签 App** | 同时装着超过 3 个就装不上，删一个再装 |
| **没有小组件与灵动岛** | 免费账号签不了扩展 + 没有 App Groups。想要就得上付费账号 |

代码里已经做了兜底：`AppGroup.defaults` 在拿不到 suite 时退化到 `.standard`，App 不会崩，只是小组件不联动。

## 常见报错对照

| 报错 | 原因 | 处理 |
| --- | --- | --- |
| `Provisioning profile doesn't support the App Groups capability` | 包里还带着 App Group 权限 | 默认已经去掉了；如果你勾了 `include_app_group`，取消重跑 |
| `Application is missing the application-identifier entitlement` | 包里有未签名的 `.appex` | 不要勾 `include_widget`，用纯主 App 包 |
| `Unable to install "水豚噜噜"` / 图标灰掉 | 已达 3 个自签 App 上限 | 删掉一个再装 |
| 点开闪退、无任何提示 | 证书 7 天到期，或未信任开发者 | 重新 Sideloadly 签一次；检查「VPN 与设备管理」 |
| `xcodebuild: error: Scheme PetApp not found` | `xcodegen` 没跑到 | 看 Actions 里「生成 Xcode 工程」那步的日志 |
| `invalid value '5.9' for '-swift-version'` | 已经修掉了，`project.yml` 里是 `5.0` | 若复现，检查是否手改了 `SWIFT_VERSION` |
| 编译过了但界面空白 | 立绘没进 bundle | 看日志里「立绘帧数」是不是 36 |

## 如果要改配置

`shared/manifest.json` 与 `shared/state.json` 是双端唯一事实源。改完：

```bash
python assets/lulu/sync_assets.py      # 同步图片 + 配置到 Android 和 iOS
```

推上去会自动触发 iOS Build（`ios/**`、`shared/**`、`assets/lulu/**` 有改动即触发）。

## 已经提前排掉的坑（本轮补充）

| 坑 | 后果 | 处理 |
| --- | --- | --- |
| `project.yml` 里写了 `info:` / `entitlements:` | XcodeGen 会**用默认内容覆写**手写 plist，`NSSupportsLiveActivities` 与 App Group 静默消失 | 已删掉这两个键，改用 `INFOPLIST_FILE` / `CODE_SIGN_ENTITLEMENTS` 直接引用 |
| `UIImage` 只靠 `import SwiftUI` | 某些编译配置下 `Cannot find 'UIImage' in scope` | 三个用到它的文件都补了 `import UIKit` |
| 内嵌 `.appex` 导致侧载签名失败 | 装不上 | CI 默认生成「纯主 App」spec（`ios/scripts/make_apponly_project.py`） |
| `strip_app_group` 需手动勾 | 忘了勾就签名失败 | 改成默认即去权限，付费账号才主动勾 `include_app_group` |
